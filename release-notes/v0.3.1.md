## 新增

- **macOS 版（部分适配）**：Apple 芯片与 Intel 通用，需要 macOS 12 及以上。
  - 可以启动 **1.19 及以上**的版本（含 Fabric、Forge、NeoForge 等加载器）。
  - **1.18 及更早的版本在 Apple 芯片上暂时无法启动**（游戏自带的 LWJGL 没有 Apple 芯片的本地库），计划在下一次大版本更新中支持。Intel Mac 不受影响。
  - 使用系统原生的窗口按钮。
  - 没有经过 Apple 公证：首次打开时如果提示「无法验证开发者」，请到「系统设置 → 隐私与安全性」中点「仍要打开」。
- **局域网互传**（工具 → 局域网互传）：在同一局域网的电脑和手机之间传输整个版本，或者模组、配置、存档、资源包等内容。接收方显示 IP、端口和配对码，导入前自动备份。
- **安卓 Java 管理**：在设置中下载、删除 Java 8 / 17 / 21 / 25，并为全局或单个版本手动选择 Java。
- **首页公告**：显示在「Minecraft 版本动态」上方，可以关闭。
- 检查更新改用 PCL.PW 官网接口（<https://pixelworld.zhuzhi.site>），国内更容易连上；官网不可用时自动改用 GitHub。

## 改进

- 正版劝导改为四个按钮：「带我去商店」「这次先启动」「试玩」「返回」。
- 版本使用的 Java 过高时提醒（例如 Forge 1.12.2 及更早的版本使用 Java 9 以上）。
- AI 助手在安卓上也能看到并设置 Java。
- 任务页的耗时每秒刷新。
- 关于页与说明文字写明：PCL.PW 是 PCL 的衍生作品，界面布局参考 PCL 社区版（PCL-CE）。

## 修复

- 安卓上安装 Forge 时库文件下载失败；预先用启动器的下载器（含镜像）下载安装器需要的库。
- 同时安装多个 Forge 时可能识别成别的版本，导致启动崩溃。
- 安卓上 Forge 1.7 ~ 1.12 启动时因加载画面崩溃（StitcherException）。
- 安卓上 Java 下载完成后任务一直停在「解压」。
