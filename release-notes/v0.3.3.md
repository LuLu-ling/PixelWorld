## 新增

- **macOS（Apple 芯片）：现在可以启动 1.12.2 及更早的版本，包括 Forge 1.12.2。**
  - LWJGL 2 使用 arm64 本地库，旧版 JNA、java-objc-bridge、text2speech 自动换成支持 Apple 芯片的版本（与 Prism Launcher 使用的相同）。
  - 需要 Java 8 的版本（Forge 1.12.2 及更早、OptiFine 独立版等）会自动下载 Azul Zulu 8（Apple 芯片原生版），按 SHA-256 校验。
  - 至此 Apple 芯片上 1.12.2、1.13～1.18、1.19 及以上都已实测可以启动。
  - 注意：部分 Apple 芯片专用的库文件只能从 GitHub 下载，如果下载失败（HTTP 504 等），请在能访问 GitHub 的网络下（或开启代理）重试。

## 修复

- Forge 等依赖原版的版本，合并原版的库时会丢掉按平台区分的同名库（例如 1.12.2 在 macOS 上的 LWJGL），导致在 Mac 上启动时找不到 LWJGL。
- macOS 上 LWJGL 2 的版本不再添加 `-XstartOnFirstThread`，否则游戏窗口不会显示。
