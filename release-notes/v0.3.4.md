## 新增

- 首页新增「更新日志」提示条，显示当前版本的更新内容，可以展开阅读全文；关闭后同一个版本不再提示，换版本后自动重新出现。
- 工具页新增「使用文档」：在启动器内阅读官网文档，可以切换页面；断网时显示最近一次缓存。
- 安卓版下载 Java 时，GitHub 连接卡住或速度过低会自动改用 ghproxy 镜像；下载和解压都显示确定进度，连接来源、速度和大小写在任务详情里。
- 电脑端下载 Java 运行时也显示已下载大小、平均速度和下载源；macOS Apple 芯片的 Zulu 8 改成按字节显示进度，不再从 0/1 直接跳到 1/1。
- 从 GitHub 下载的文件（macOS Apple 芯片的兼容库、文档的备用源）直连失败或卡住时，会自动尝试 ghproxy 镜像。
- 安卓游戏内新增可拖动的助手小球：点开可以查看基础信息（内存、CPU、温度、运行时长，Zink 渲染器还能看帧率），也可以直接「问 AI」；AI 请求通过启动器发出，密钥不会进入游戏进程。手上暂时没有空位时可以拖到屏幕边缘，也可以在设置里关闭。

## 修复

- 安卓第一次安装 APK 更新时，如果还没有授予「安装未知应用」，不再报错并要求重新下载；安装包会保留，授权后点「继续安装」即可。
