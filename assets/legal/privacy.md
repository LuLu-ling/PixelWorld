# Pixel World 隐私说明

生效日期：2026 年 11 月 16 日

本说明介绍 Pixel World 会在你的设备上保存什么、会连接哪些服务，以及发送什么内容。

## 1. 我们不收集你的信息

- 本软件**没有**作者运营的账户系统，**不**收集使用统计，**不**上传崩溃报告，也**不**上传你的文件。
- 作者的网站（pixelworld.paperzhu.com）只提供检查更新、启动器公告和使用文档所需的静态文件。访问时不会发送你的账户信息；网站和托管服务可能按惯例记录 IP 地址等访问日志。

## 2. 保存在你设备上的信息

以下内容只保存在你的电脑或手机上：

- 账户信息和登录凭据（Microsoft 账户的登录令牌、外置登录的令牌、离线账户名）
- AI 服务的接口地址、模型和密钥，以及你和 AI 的聊天记录
- 启动器的设置、背景图片、下载的游戏文件、存档和日志

删除启动器的数据文件夹即可清除这些信息。安卓上卸载启动器会清除应用内部的数据；如果你选择把游戏文件放在手机存储里，这部分文件会保留，需要你自己删除。

## 3. 会连接的服务

使用相应功能时，启动器会直接连接以下服务：

| 服务 | 用途 | 发送的内容 |
| --- | --- | --- |
| Microsoft、Xbox Live、Mojang | 正版登录、检查游戏所有权、获取皮肤 | 登录过程中的授权信息和令牌 |
| 外置登录服务（例如 LittleSkin） | 你选择外置登录时 | 你填写的账户和密码 |
| Mojang、BMCLAPI 等下载镜像，Forge、NeoForge、Fabric、Quilt 等加载器仓库 | 下载游戏、加载器和运行库 | 要下载的文件名称 |
| Modrinth | 搜索和下载模组、整合包、资源包、光影 | 搜索关键词和游戏版本 |
| GitHub 及其加速镜像、pixelworld.paperzhu.com | 检查更新、读取公告和使用文档 | 当前版本号 |
| 中文 Minecraft Wiki | 首页的 Minecraft 版本动态 | 无个人信息 |
| 你查询的 Minecraft 服务器 | 服务器查询、服务器在线人数 | 服务器地址 |
| 你配置的 AI 服务商，以及你开启的联网搜索服务 | AI 助手 | 你发送的内容，以及你允许 AI 读取的日志和文件 |

局域网互传只在同一局域网内的设备之间直接传输，不经过任何服务器。

这些服务由第三方运营，它们如何处理数据，以各自的隐私政策为准。

## 4. 安卓权限

- **网络**：下载游戏、登录、检查更新等。
- **所有文件访问权限**：只在你选择把游戏文件放在手机存储里时请求，用来读写这个文件夹。
- **安装应用**：只在你确认更新启动器时使用，用来安装新版本。

## 5. 说明的更新

本说明可能会更新。更新后，启动器会在启动时请你再次确认。
